# Glossary

- **Assessment**: evidence-backed classification for one repository.
- **Counter-evidence**: facts that argue against deletion.
- **Deep probe**: additional read-only checks for candidate-like repositories.
- **DELETE_CANDIDATE**: advisory label for a deeply verified empty repository.
- **MANUAL_REVIEW**: evidence is incomplete or requires contextual judgment.
- **Decision export**: local JSON record of user choices; it has no execution capability.
